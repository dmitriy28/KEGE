# Инструкции для ИИ-агентов

Этот репозиторий содержит приложение KEGE Station и формат экзаменационных пакетов `.kege`.

## Перед изменением кода

1. Прочитайте `README.md` и относящиеся к задаче файлы из `docs/`.
2. Не добавляйте в Git реальные `.kege`, `.kege-result`, PDF с заданиями, архивы дополнительных файлов, ключи ответов, базы SQLite и журналы.
3. Не изменяйте формат пакета без обратной совместимости и обновления `docs/PACKAGE_FORMAT.md`.
4. После изменений выполните компиляцию и все тесты.

## Сборка экзаменационного пакета

Если пользователь передал PDF, архив дополнительных файлов и ответы, полностью следуйте `docs/BUILD_PACKAGE.md`.

Обязательные правила:

- условия переносятся в HTML-текст, а не вставляются снимками страниц PDF;
- изображениями остаются только графики, схемы, таблицы, которые нельзя надёжно выразить HTML, и иные действительно визуальные элементы;
- формулировки не сокращаются и не пересказываются;
- каждый файл задания связывается только с правильным номером задания;
- исходный PDF с ответами никогда не помещается внутрь `.kege`;
- ключи находятся только в зашифрованной секции;
- неизвестный ответ не выдумывается — он отмечается в отчёте как требующий ручной проверки;
- источник и статус неофициальной адаптации указываются в поле `source`;
- материалы третьих лиц не коммитятся в публичный репозиторий.

Перед выдачей результата обязательно запустите:

```bash
python tools/validate_exam_package.py output.kege --password "EXPERT_PASSWORD" --expect-tasks 27 --strict
```

Затем импортируйте пакет в KEGE Station и визуально откройте каждое задание хотя бы в одном варианте. Проверьте длинные условия, таблицы, изображения и открытие дополнительных файлов.

## Итог агента

Агент должен вернуть:

1. готовый `.kege`;
2. ZIP-копию для удобного скачивания;
3. `BUILD_REPORT.md` с источниками, количеством вариантов и заданий, перечнем вложений, отсутствующими или сомнительными ответами, результатом валидатора и SHA-256;
4. созданный для конкретного источника скрипт сборки — отдельно от публичного репозитория, если в нём присутствует защищённый текст заданий.

## Проверка проекта

```bash
python -m compileall -q kege_app run.py tools
python -m unittest discover -s tests -v
python tools/build_package_example.py /tmp/kege-example.kege --password test-password
python tools/validate_exam_package.py /tmp/kege-example.kege --password test-password --expect-tasks 2 --strict
```
