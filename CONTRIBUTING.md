# Как предложить изменение

Спасибо за интерес к KEGE Station.

1. Создайте fork репозитория и отдельную ветку от `main`.
2. Не добавляйте реальные экзаменационные пакеты, ключи ответов, базы SQLite, журналы и персональные данные учеников.
3. Сохраняйте совместимость с Python 3.11+ и PyQt6.
4. Перед коммитом выполните:

```bash
python -m compileall -q kege_app run.py
python -m unittest discover -s tests -v
```

5. В pull request кратко опишите проблему, решение и способ ручной проверки интерфейса.

Для крупного изменения сначала создайте Issue, чтобы согласовать формат данных и поведение интерфейса.
