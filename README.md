<h1 align="center">KEGE Station</h1>

<p align="center">Офлайн-тренажёр компьютерного ЕГЭ по информатике на Python и PyQt6.</p>

  <img alt="Python 3.11+" src="https://img.shields.io/badge/Python-3.11%2B-3776AB?logo=python&logoColor=white">

  <img alt="License MIT" src="https://img.shields.io/badge/license-MIT-0b7285">
</p>

KEGE Station имитирует рабочее место участника компьютерного экзамена: регистрация, инструкция, активация, таймер, задания с дополнительными файлами, ввод ответов и завершение с контрольной суммой. В режиме эксперта можно импортировать экзаменационные пакеты, просматривать и проверять работы.

> Проект является независимым учебным тренажёром и не связан с ФИПИ, Рособрнадзором или официальным программным обеспечением экзамена.

## Возможности

- автономная работа без сервера и подключения к Интернету;
- случайный выбор варианта из импортированного пакета;
- HTML-условия, изображения, краткие и табличные ответы;
- открытие файлов заданий в Excel, LibreOffice и других системных программах;
- локальная база результатов SQLite;
- защищённый паролем режим эксперта;
- ручная и автоматическая сверка, баллы и комментарии;
- экспорт результата в `.kege-result`;
- зашифрованные ключи ответов внутри `.kege`;
- журнал событий и окно с отчётом об ошибке;
- предупреждение при попытке закрыть программу во время экзамена.

## Быстрый запуск

Требуется Python 3.11 или новее.

### Windows

```powershell
git clone YOUR_REPOSITORY_URL
cd KEGE-Station
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python run.py
```

### Linux/macOS

```bash
git clone YOUR_REPOSITORY_URL
cd KEGE-Station
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python run.py
```

При первом запуске список экзаменов пуст. Импортируйте собственный пакет `.kege` через режим эксперта.

## Сборка Windows-приложения

Запустите `build_windows.bat`. Готовая переносимая программа появится в `dist\KEGE_Station\KEGE_Station.exe`.

Windows-сборку необходимо выполнять в Windows: PyInstaller не поддерживает кросс-компиляцию `.exe` из Linux. Для тегов вида `v1.3.0` GitHub Actions автоматически подготовит Windows-артефакт.

## Первый вход эксперта

- пароль по умолчанию: `KEGE-2026`;
- код активации задаётся создателем пакета;
- номер бланка в тренировочном режиме — любые 13 цифр.

После первого запуска обязательно измените пароль на вкладке «Безопасность». Не используйте пароль по умолчанию при реальной работе с результатами учеников.

## Экзаменационные пакеты

В репозитории намеренно отсутствуют реальные задания, ключи и дополнительные файлы экзаменов. Это исключает случайную публикацию материалов с ограниченными правами и правильных ответов.

- `.kege` — ZIP-контейнер с манифестом, вариантами, условиями, вложениями и зашифрованными ключами;
- `.kege-result` — контейнер с ответами участника и, после проверки, экспертной ведомостью.

Файлы этих типов игнорируются Git. Храните рабочие пакеты отдельно и не добавляйте в публичный репозиторий персональные результаты учеников.

### Сборка пакета из PDF и архива

Для самостоятельной или агентской сборки добавлены:

- [пошаговая инструкция](docs/BUILD_PACKAGE.md);
- [техническое описание формата](docs/PACKAGE_FORMAT.md);
- [универсальный промт для ИИ-агента](docs/AGENT_PROMPT_RU.md);
- рабочий пример `tools/build_package_example.py`;
- строгий валидатор `tools/validate_exam_package.py`.

Минимальная проверка готового варианта:

```bash
python tools/validate_exam_package.py Exam.kege \
  --password "EXPERT_PASSWORD" \
  --expect-variants 1 \
  --expect-tasks 27 \
  --strict
```

Официальные открытые варианты следует скачивать непосредственно с сайта правообладателя. Репозиторий предоставляет инструменты локальной адаптации, но не распространяет копии экзаменационных материалов.

## Проверка проекта

```bash
python -m compileall -q kege_app run.py
python -m unittest discover -s tests -v
python tools/build_package_example.py /tmp/kege-example.kege --password test-password
python tools/validate_exam_package.py /tmp/kege-example.kege --password test-password --expect-tasks 2 --strict
```

Проверки автоматически запускаются через GitHub Actions для Python 3.11 и 3.12.

## Данные и журналы

База, импортированные пакеты, кэш и распакованные файлы заданий сохраняются в стандартном каталоге данных приложения пользователя. Для изолированного запуска можно указать собственную папку:

```bash
KEGE_DATA_DIR=/path/to/test-data python run.py
```

В подпапке `logs` создаются `kege_station.log` и `native_crash.log`. Перед публикацией отчёта проверьте журнал: путь к открытому файлу может содержать имя пользователя Windows.
