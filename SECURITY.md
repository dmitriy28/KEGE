# Политика безопасности

Не публикуйте сведения об уязвимости, реальные ключи ответов, базы результатов или журналы с персональными путями в открытом Issue.

Сообщение должно содержать версию программы, операционную систему, сценарий воспроизведения и очищенный от персональных данных фрагмент журнала. Контакт для приватного сообщения владелец репозитория может указать в разделе **Security → Private vulnerability reporting** на GitHub.

Поддерживается актуальная версия из ветки `main`. Пароль эксперта по умолчанию предназначен только для первого тестового запуска и должен быть изменён пользователем.
