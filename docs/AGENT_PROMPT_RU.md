# Универсальный промт для сборки пакета

Скопируйте текст ниже в чат с ИИ-агентом и приложите PDF, архив дополнительных файлов и файл ответов.

---

Ты работаешь с открытым проектом KEGE Station. Сначала изучи `AGENTS.md`, `docs/BUILD_PACKAGE.md`, `docs/PACKAGE_FORMAT.md`, `kege_app/models.py`, `kege_app/package_io.py`, `kege_app/security.py` и `tools/build_package_example.py`.

Мне нужно собрать готовый экзаменационный пакет `.kege` из приложенных исходников:

- PDF с вариантами и условиями;
- архив дополнительных файлов к заданиям;
- PDF/таблица/текст с правильными ответами;
- при наличии — официальный URL источника.

Параметры пакета:

- название: `<УКАЗАТЬ>`;
- предмет: `Информатика`;
- год: `<УКАЗАТЬ>`;
- продолжительность: `<УКАЗАТЬ>` минут;
- код активации: `<УКАЗАТЬ>`;
- пароль шифрования ключей: `<УКАЗАТЬ>`;
- ожидаемое число вариантов: `<УКАЗАТЬ>`;
- ожидаемое число заданий в варианте: `<УКАЗАТЬ>`.

Выполни весь объём без остановки после нескольких заданий.

Требования:

1. Определи точные границы вариантов и всех заданий, включая продолжения на следующих страницах.
2. Перенеси условия полностью и максимально точно в HTML. Не сокращай и не пересказывай текст.
3. Не используй снимки страниц или целых условий. В изображениях оставь только графики, схемы и элементы, которые нельзя корректно представить HTML.
4. Таблицы сделай настоящими HTML-таблицами, код — блоками `<pre>`, индексы — `<sup>/<sub>`.
5. Сопоставь каждый файл архива с правильным заданием. Проверь, что ODS/ODT/TXT и другие файлы реально открываются.
6. Извлеки ответы только из предоставленного источника. Ничего не угадывай. Неоднозначные ответы перечисли в отчёте и оставь для ручной проверки.
7. Для многопольных ответов используй `answer_type="table"` и двумерные списки ключей.
8. Не помещай исходные PDF и открытые ответы внутрь пакета. Ключи должны находиться только в зашифрованной секции.
9. В поле `source` укажи источник и фразу о неофициальной технической адаптации. Не используй логотип и не заявляй об одобрении со стороны правообладателя.
10. Создай воспроизводимый локальный скрипт сборки на Python через `ExamPackage`, `Variant`, `Task`, `Attachment` и `create_package()`.
11. Запусти строгий валидатор с ожидаемым количеством вариантов и заданий.
12. Визуально проверь в KEGE Station каждое задание хотя бы одного варианта, а также все уникальные типы заданий в остальных вариантах.

Итоговые файлы:

- готовый `.kege`;
- ZIP с этим `.kege`;
- `BUILD_REPORT.md`;
- скрипт сборки;
- при необходимости отдельная папка только с извлечёнными графиками и схемами.

В `BUILD_REPORT.md` укажи источники, количество вариантов, количество заданий, перечень вложений, пропущенные или сомнительные ответы, результат автоматической и визуальной проверки и SHA-256 итоговых файлов.

Не публикуй исходники и готовый пакет в открытом репозитории без подтверждения прав на распространение.
